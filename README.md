# TURF CLUB — 日本競馬體驗

以原生 ESM JavaScript、Three.js 製作的日式 3D 賽馬遊戲。先看出馬表、選擇競猜，再觀看完整轉播、最後直線重播與點數結算。

## 啟動（不需安裝依賴、不需 build）

```sh
node scripts/serve.mjs 8770
```

開啟 <http://localhost:8770>。也可使用 `npm run dev`；這只是啟動靜態 HTTP 伺服器。

瀏覽器透過 import map 直接載入 `src/*.js` 與 `vendor/three/` 的原生 ES 模組。所有遊戲模型、圖片、音效與 HDR 位於 `public/assets/`，採相對模組路徑，支援儲存庫子目錄。頁面字型使用 Google Fonts 並提供系統字型備援。

GitHub Pages 設定：**Deploy from a branch → main → / (root)**。直接發布儲存庫即可；`.nojekyll` 停用 Jekyll，無 Vite、打包步驟或產物目錄。請透過 HTTP 開啟，勿雙擊 HTML。

僅在開發／執行自動測試時需要 `npm ci`；遊戲本身不需要 npm 安裝。

## 已實作

- 12 匹虛構賽馬與 12 位虛構騎師；正確的 12 頭出賽枠色分配。
- 賽前狀態、年齡、馬體重與增減、負重、近期名次、速度、持久力、騎師技巧及草地適性。
- 原創日式賽場、真實網格馬匹及騎師、骨架疾馳動畫、閘門、看台、欄杆、草地與環境光。
- 360° 馬匹檢視：拖曳旋轉、滾輪 / 觸控縮放。
- 單勝、複勝、馬連、馬單、位置連贏、三連複、三連單、框連；順序型依點選順序標記名次，同枠組合會驗證該枠有兩匹。
- 每場最多 20 注；每注 100–10,000 點；加入預測單即固定遊戲賠率，開賽扣點。
- 固定時間步長的賽程模擬；能力、狀態、跑法、配速、末段加速、體力及跑線空間共同影響表現。每場種子獨立，不由選馬決定勝負。
- 六個轉播鏡位：閘門、側面追拍、空拍、長焦、跟隨騎手、終點；自動導播與手動切換。
- 即時順位、剩餘距離、計時、賽況字幕、馬場位置圖與預測馬標記。
- 暫停、1× / 2× / 4×、全螢幕；最後直線 0.5× 重播。
- 全 12 匹抵達後才確認結果；依實際跨線時間排序，重播不重複結算。
- localStorage 保存點數；重新整理未完成賽事會退款；遊戲說明內可重設 10,000 點。
- 自適應桌面 / 手機介面、觸控選馬、音效開關與基本鍵盤操作。

## 遊玩

1. 在出馬表勾選馬匹；點「＋」可查看詳細狀態。
2. 右側選玩法、點數，再按「加入預測單」。亦可只觀戰。
3. 按「確認預測・開始觀看」，倒數三秒後開閘。
4. 切換鏡位或速度；空白鍵可暫停 / 繼續。
5. 賽後查看結算，或重播最後直線，按「下一場」再玩一場。

## 驗證

```sh
npm test
npm run test:browser
```

瀏覽器測試預設使用 macOS Google Chrome；其他環境請設定 `CHROME_PATH`。可用 `TEST_URL` 指向靜態網站伺服器。

- 20 項動畫、音效、跑線、模擬與票種測試：勝負、順序、同枠組合、非法輸入、鎖定賠率、確定性、完整賽程、重播資料與不同勝者。
- Playwright：桌面 1440×1000 與手機模擬 390×844，整場開賽至 12 匹抵達、結算、重播不重複付款、下一場、重新整理退款、手機觸控與水平溢位。
- 瀏覽器驗證輸出在 `artifacts/`，包含各鏡位、馬匹檢視、桌機 / 手機畫面及 `browser-report.json`。
- 手機證據來自 Chrome 觸控模擬，並非實體手機效能測試。

## 製作範圍

這是可玩的原創日式賽馬體驗，不是 JRA 官方產品；賽道不是中山競馬場的精確測繪重建。3D 模型與動畫屬網頁遊戲品質，並非電影級或實際轉播畫面。場景採用真實 3D 主體與遠景植被圖片以兼顧效能。

目前為固定天氣與 2,200m 賽事；沒有多人連線、真實賽事資料、真實彩池賠率、語音主播或現金金流。賽程比例為遊戲化配置，計時不能作真實馬匹表現比較。

### 漸進搶位與步幅同步

路線改為每次只規劃最多 1.6 公尺的橫移，維持至少 3 秒的路線決策，橫向速度上限 0.45 公尺／秒、加速度上限 0.22 公尺／秒²。由起跑後 55–505 公尺漸進收攏，檢查整段橫移通道是否有鄰馬；無空間時先跟跑減速。模型朝向納入實際橫向速度。

步態減少過度收腿，步伐相位由前進距離累計，隨速度自然加快或放慢，重播與終點攝影沿用同一相位。`tests/movement.test.js` 驗證三場完整賽事的橫移速度、加速度、跑道邊界與步幅同步。

目前音效使用 Joseph Sardin / BigSoundBank #1850 CC0 真馬草地疾馳錄音，保留自然節奏與音高；不再使用人的腳步擬音。跑姿依使用者提供的 Muybridge 分解圖調整收腿與騰空時序，可在賽前「慢動作跑姿」檢視。
