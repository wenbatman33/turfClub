# 步態實作與限制

## 動作參考

- 使用者提供的 [賽馬影片](https://www.youtube.com/watch?v=BU7J3UJR-bo)。
- [馬匹跑步分解](https://andyeee.blogspot.com/2010/12/blog-post_17.html) 中的 Muybridge 連拍與跑姿示意。

參考用於手工編排動作，沒有把影片或分解圖片納入遊戲素材，也不是動作捕捉或精確生物力學量測。

## 骨架與相位

`scripts/prepare-horse.py` 使用原始馬模型製作 Idle / Gallop 動畫。小腿採剛性權重，只在關節附近混合；前腿與後腿使用不同的收折方向、蹄部回收路徑與雙關節解算。

每個循環的支撐起點為後腿 0 / .12、前腿 .38 / .50，各支撐 .22 週期；.72–1 為收腿騰空。回收曲線以 Hermite 插值銜接。`race.js` 依前進距離累計步伐相位，重播沿用記錄的相位。

## 平滑馬身高度

`scene.js` 載入時以 256 個相位及蹄部表面採樣校準高度；`gait-height.js` 保留兩個低頻諧波，形成連續、首尾銜接的週期曲線，覆寫 GLB 根節點高度。騎師和號碼布跟隨同一路徑。

執行時不逐幀依最低蹄推動整匹馬，也不依賴前一幀的阻尼狀態，因此反向審視終點與重新定位可得到相同姿勢。保留離地餘量的代價是支撐蹄可能與草地有少量間距；此版本沒有完整的足部接觸物理。

`tests/gait-height.test.js` 檢查週期銜接與平滑性；`tests/gait-support.mjs` 在瀏覽器內檢查蹄部高度、馬身高度變化及循環接縫。
