# 跑姿修正依據

參考：https://www.youtube.com/watch?v=BU7J3UJR-bo&t=101s

本次在 YouTube 播放器實際暫停並以逐格鍵觀察約 1:41–1:42 的側面馬群畫面（主要看 5 號馬），不是僅讀影片文字。直接下載片段失敗，未將 JRA 影片納入遊戲素材。

可觀察到：前肢向前伸展後承重，後肢蹬向後方再往腹下回收；四足帶相位差，並非四腿同時擺動。小腿骨段維持筆直，動作集中在關節；騎師軀幹相對穩定。欄杆與其他馬匹遮擋部分足部，故不能從這段影片精確量出所有關節角度或每足接觸時刻。

## 找到的錯誤與修改

1. 雙骨 IK 原本前後腿都選相同的彎折分支，前腿折向錯誤；現在前肢腕關節與後肢飛節使用相反的解算分支。
2. 原先肩部固定，現在肩部與髖部先擺動，再於其座標下解算下方關節。
3. 小腿蒙皮過寬，改為骨段單骨剛性權重，只保留腕／飛節附近 0.45 模型單位的過渡帶。
4. 重做前伸、承重、收腿的相位；動畫相位隨前進距離累計。
5. 模型展示加入「慢動作跑姿」，可以旋轉視角檢查關節，不必等整場比賽。
6. 當時曾用沙地腳步擬音；本次已淘汰並改為 Joseph Sardin 的真馬草地錄音，見 ASSETS.md。

這是參考影片後重製的關節動畫，不是影片動作捕捉。三維姿態、相位與聲音仍屬遊戲近似。


## 使用者補充分解圖（本次修訂）

已查看 https://andyeee.blogspot.com/2010/12/blog-post_17.html 的 Muybridge 連拍與 runhorse 分解圖。原先每一幀強制最低蹄貼地，消除了收腿騰空，這是明確錯誤。

本次將一週期支撐起點改為後腿 0 / .12、前腿 .38 / .50，支撐長 .22；.72–1 為收腿騰空。前腿先向後收折再向前伸，後腿較早回收到腹下，兩者使用不同蹄部曲線；關節曲線使用 Hermite 插值，小腿剛性權重保留。騰空最高 .15 場景單位。這些是按分解圖重新編排的手工動畫參數，不是動作捕捉或由影像測量而得的精確生物力學數值。


## 抖動修正

先前每幀選最低蹄推回地面，導致支撐腳交替時整個馬身高度折返；GLB 原始根節點亦包含高頻高度補償。
遊戲現在在載入時用 256 個相位採樣校準，僅保留兩個低頻諧波形成週期高度路徑，直接覆寫根節點高度。騎師與號碼布跟隨同一路徑，不再每幀重新計算蹄部世界座標。保留離地餘量，避免用逐幀硬限制再次引入抖動；代價是支撐蹄與草地可能有少量間距，並非完整足部接觸物理。
`tests/gait-support.mjs` 量測完整週期：身高變化約 0.0845 場景單位，接縫高度差 0；檢查最高二階差分，避免細碎抖動再次回歸。此曲線依相位決定，不依前一幀，因此倒放和終點攝影可重現同一姿勢。
